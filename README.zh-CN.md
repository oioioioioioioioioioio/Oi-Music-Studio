# 0i-Studio

[English](README.md) | **简体中文**

基于 C++20 和 JUCE 开发的专业多轨、空间音频编辑器，支持 Windows 桌面端与 Android 手机和平板。

当前版本：**0.1.10**（Android `versionCode 11`）。

## 当前功能

- 专业的剪辑、空间和混音工作区
- 支持暗色/亮色主题，以及运行时中英文切换
- 可调整素材库、检查器、轨道和混音器的布局尺寸
- 默认仅创建一条空轨道；用户可自行添加、命名和重命名轨道（最多 12 条），并显示真实波形缩略图和片段元数据
- 支持显式导入多个文件或文件夹、从素材库拖放到任意轨道、在时间标尺上定位、选择片段、分割、同轨或跨轨移动、复制、删除、撤销和重做
- 同一轨道内支持片段边缘自动吸附，并显示吸附参考线；按住 `Alt` 可临时关闭吸附
- 时间线导航：触摸屏上可用一根手指拖动标尺或空白轨道区域进行平移，用两根手指缩放；桌面端使用 `Ctrl+滚轮` 缩放、`Alt+滚轮` 横向滚动，按 `Space` 播放或暂停
- 时间线标题栏的 `+` 按钮会打开与“轨道”菜单相同的命名轨道对话框
- 实时多轨混音，支持每轨音量、声像、静音、独奏和电平表
- 支持片段增益、主音量、播放定位、循环播放和倍速播放
- 支持逐轨空间渲染，包括启用/旁路、半径、方位角、仰角、旋转速度、声源宽度、指向性、衰减曲线和可选空气吸收
- 可在连续的轨道级 3D 空间效果上，为片段局部范围设置空间参数和相对音量自动化，并调整平滑进入/退出过渡和时间线包络；横屏手机顶部固定工具栏提供范围选择工具，不会遮挡波形
- Android 参数数值仅用于显示，完整参数行不会获取文本焦点；点击标题、数值或滑杆均不会弹出软键盘
- 支持离线导出 PCM WAV：44.1/48/88.2/96 kHz、16/24/32 位，以及立体声、5.1、7.1、5.1.4 和 7.1.4 声道布局
- Windows 和 Android 均支持中英文 GitHub Release 更新检查；Android 可在应用内下载 APK，验证 SHA-256、包信息和签名后交给系统安装器，并支持手动检查更新

### 在线更新

两个客户端都会在启动后稍作延迟，检查本仓库最新的 GitHub Release。检查在后台线程执行；当前版本已是最新或网络不可用时不会打扰用户。Windows 可通过 **文件 > 检查更新** 手动检查，Android 可通过 **更多 > 检查更新** 手动检查并查看结果。

更新必须由用户确认。Windows 会打开已发布的 `.exe` 下载；Android 会将 `.apk` 下载到应用私有存储，依次校验 Release 摘要、包名、版本和签名证书，然后打开系统安装器。Android 首次使用时可能要求允许 0i-Studio“安装未知应用”；Android 不允许普通应用静默安装更新。Release 资产必须使用以下命名，客户端才能选择对应平台的软件包：

- `0i-Studio-<version>-windows-x64.exe`
- `0i-Studio-<version>-android.apk`

### 菜单和素材库

顶部菜单均为可用的编辑入口，不是占位内容：

- **文件**：导入音频、更改素材文件夹、打开导出和音频设备设置、检查更新，以及查看联系方式。
- **编辑**：撤销/重做、复制/删除片段、在播放头处分割，以及切换选择、范围和分割工具。
- **轨道**：将音频导入所选轨道、切换静音/独奏/3D 渲染、重置轨道混音，以及选择轨道。
- **剪辑**：分割、复制、删除片段，重置片段增益，删除所选空间范围，以及将片段移动到其他轨道。
- **视图**：切换剪辑/空间/混音工作区、显示或隐藏面板、打开布局设置，以及切换主题和语言。

左侧素材库包含“工程”“本地”和“空间预设”页面。素材库默认为空，只显示用户明确导入的文件或文件夹，不会扫描固定磁盘。导入的素材可以直接拖到指定轨道，也可以双击添加到播放头位置。工程条目可在时间线中定位片段；空间预设可将一整套空间参数应用到所选轨道或空间范围。搜索和刷新仅作用于当前页面。

当前 JUCE 读取链路已验证 WAV、AIFF、FLAC、OGG 和 MP3。素材库可以列出 M4A 文件，但 AAC/M4A 解码仍需要额外的编解码后端；目前导入这些文件时会显示正常的格式不支持提示。

联系方式位于 Windows 的 **文件 > 关于与联系方式**，以及 Android 的 **更多 > 关于与联系方式**：QQ 2224248204。

空间渲染器是实时的扬声器对象声像器。在立体声设备上，它使用确定性的伪双耳耳间延迟、头部阴影滤波以及后方/高度频谱线索；由于尚未集成实测 HRTF/SOFA 数据集，立体声模式仍无法保证可靠的前后或垂直方向定位。在 4.0、5.0、5.1、6.1、7.1、5.1.4 和 7.1.4 输出配置中，声源位置会分配到对应的扬声器声场。距离控制音量衰减；存在高度扬声器时，仰角会选择高度声道；旋转速度支持每个时间线秒 -360 至 +360 度；指向性控制扬声器分布宽度；声源宽度在立体声中保留可控扩散感。范围工具可创建局部空间和相对增益覆盖；独立 DSP 路径使用平滑步进包络逐采样交叉淡化，并共享时间线旋转相位，因此每个范围之外的基础 3D 渲染保持连续。空间画布会显示当前音频设备布局、旋转相位、速度和每圈秒数。旋转依据时间线时间运行，因此播放倍速会改变真实时间中的旋转速度。离线 WAV 导出共用同一个渲染器，并按照选择的扬声器布局写入文件，不会改变实时播放状态。当前引擎会将导入音频解码到内存，并使用线性重采样实现播放倍速，因此速度变化也会改变音高。音高锁定、录音、效果器、保音高时间拉伸、多普勒处理、听者头部跟踪和实测 HRTF 渲染仍需要专用 DSP 后端。

## Windows 构建

环境要求：

- Visual Studio 2022 或更高版本，并安装“使用 C++ 的桌面开发”
- CMake 3.22 或更高版本
- 将 JUCE 8.0.13 放置于 `external/JUCE`

```powershell
cmake -S . -B build -G "Visual Studio 18 2026" -A x64
cmake --build build --config Release
```

可执行文件会生成到 `build/OiMusicEditor_artefacts/Release/`。

## Android 手机和平板构建

Android Studio 工程位于 `Builds/Android`。最低支持 Android 7.0/API 24，并生成 `armeabi-v7a`、`arm64-v8a` 和 `x86_64` 原生库。手机和平板共用同一套 JUCE 组件树，界面会在运行时选择三种响应式模式：

- 手机：小于 600 dp，使用适合触控的控件和抽屉面板；
- 紧凑型平板：600-1023 dp，使用更紧凑的多栏面板；
- 完整布局：1024 dp 及以上，使用桌面风格工作区。

可以在 Android Studio 中打开 `Builds/Android`，也可以在 PowerShell 中构建：

```powershell
cd Builds/Android
.\gradlew.bat assembleDebug --offline --no-daemon --console=plain
```

调试 APK 会生成到 `Builds/Android/app/build/outputs/apk/debug/app-debug.apk`。连接手机或平板后，可使用 `adb install -r` 安装。应用通过 Android 系统文件选择器显式导入音频，不会扫描固定磁盘，也不需要访问 `E:\`。

JUCE 的 `juceaide` 是主机端可执行文件，不能由 Android NDK 构建。CMake 会自动复用普通 Windows 桌面构建产生的工具（`build/external/JUCE/tools/.../juceaide_artefacts/Custom`）。如果构建目录位于其他位置，请显式传入其所在目录：

```powershell
.\gradlew.bat assembleDebug --offline --no-daemon --console=plain `
  -PoiJuceHostToolsDir=C:/path/to/juceaide_artefacts/Custom
```

也可以先配置并构建一次桌面目标，让 JUCE 生成主机工具，然后重新构建 Android。`ANDROID_HOME` 或 `ANDROID_SDK_ROOT` 应指向已安装的 SDK。离线安装 SDK 时，请向 Gradle 传入 `-Pandroid.aapt2FromMavenOverride=C:/path/to/Android-SDK/build-tools/<version>/aapt2.exe`。不要提交与本机绑定的 SDK 路径。

## 测试

测试套件覆盖更新版本比较、多轨混音求和、静音、声像、分割、跨轨移动、复制、删除、时间线缩短后的播放头限制、撤销/重做、倍速播放推进、范围空间/音量自动化、边界连续性、立体声、5.1 环绕和 5.1.4 高度布局的确定性空间渲染，以及 24 位立体声/5.1 WAV 导出的元数据、时长、采样、路由、自动化保留和实时播放状态隔离。

```powershell
cmake --build build --config Release
ctest --test-dir build -C Release --output-on-failure
```
